What do I import, and why?

PyRIT doesn't have one page that maps "thing I want to build" → "imports I need." This page does that: pick what you're building below, and it shows the minimal import list plus the reasoning behind each line. Built to complement your config builder for people who want to write the script by hand. Official docs: microsoft.github.io/PyRIT/1.0.1

Read this first — the #1 source of confusion. Older tutorials, blog posts, and even some 2025-era notebooks import from pyrit.orchestrator import PromptSendingOrchestrator / RedTeamingOrchestrator / CrescendoOrchestrator. That's the pre-1.0 API. PyRIT 1.0+ renamed and moved these into pyrit.executor.attack as PromptSendingAttack / RedTeamingAttack / CrescendoAttack, with a standardized config pattern (AttackAdversarialConfig, AttackScoringConfig, AttackConverterConfig) instead of each orchestrator taking different constructor arguments. If a guide's imports don't match what's below, it's written for an older version — don't mix the two APIs in one script.

The module map — what each package is responsible for

pyrit.setupBoots PyRIT: initialize_pyrit_async() + memory type constants (IN_MEMORY). Always your first import.
pyrit.prompt_targetThe system under test (and the attacker/judge LLM) — OpenAIChatTarget, HTTPTarget, etc.
pyrit.executor.attackThe attack strategies themselves — PromptSendingAttack, RedTeamingAttack, CrescendoAttack, PAIRAttack/TAPAttack + their config objects.
pyrit.prompt_converterPrompt-level obfuscation/transforms applied before sending — Base64, ROT13, translation, role-play framing…
pyrit.prompt_normalizerGlue that turns a list of converters into a config the attack can consume (ConverterConfiguration).
pyrit.scoreJudges the response — SelfAskTrueFalseScorer, SelfAskRefusalScorer, SubStringScorer, RegexScorer…
pyrit.datasetsLoads objective/seed-prompt sets — TextJailBreak and dataset fetchers.
pyrit.memoryWhere conversations/scores land — CentralMemory, SQLite/Azure SQL backends.
pyrit.modelsShared data types passed between components, e.g. Message.
pyrit.registryNames and looks up targets by string — TargetRegistry, used when you register a custom target.
pyrit.authCloud auth helpers — get_azure_token_provider for Entra ID instead of API keys.
